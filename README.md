# KONNRA Official Website

Modern Astro + Cloudflare Architecture for [Dongguan Konnra Electronics Co., Ltd.](https://konnra.com).

## Highlights
- **High Performance**: Pure static generation (SSG) hosted on Cloudflare Global Edge Network.
- **GEO & AI Ready**: Native `llms.txt`, full `Schema.org` (Product, Dataset, FAQ, Organization credentials).
- **Interactive Cross-Reference**: 840+ part number mappings for JST and Molex replacements.
- **Lead Capture**: Cloudflare Serverless Form Handling + WhatsApp Instant Routing.

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Production build
npm run build
```
